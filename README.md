# 🎓 Student Information Management System

A simple Student Information Management System developed as a mini project to manage student records efficiently. This application allows users to store, view, update, and delete student information through an easy-to-use interface.

## 📌 Features

- Add new student records
- View all student details
- Search students by ID or Name
- Update existing student information
- Delete student records
- Store data using a database
- User-friendly interface

## 🛠️ Technologies Used

- Programming Language: Python
- Database: SQLite / MySQL
- **GUI**: Tkinter (if applicable)
- **IDE**: VS Code

## 📂 Project Structure

```text Student Info Project/ │ ├── main.py ├── database.py ├── student.db ├── assets/ ├── screenshots/ ```

## 🚀 Installation

### 1. Clone the Repository

```bash git clone [https://github.com/yatamilan/Student-DataBase-Mini-Project.git](https://github.com/yatamilan/Student-DataBase-Mini-Project.git) ```

### 2. Navigate to the Project Directory

```bash cd Student-DataBase-Mini-Project ```

### 3. Install Required Packages

```bash pip install -r requirements.txt ```

### 4. Run the Application

```bash python main.py ```

## 📖 Usage

## Launch the application.

## Enter student details. ## Save records to the database. ## Search, update, or delete records as needed. ## View all stored student information.
